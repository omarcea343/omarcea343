# Hi, I'm Omar 👋

Full-stack developer based in Aguascalientes, Mexico. I build and ship web products end to end — from database schema to deployed infrastructure — mostly with **Next.js, TypeScript, PostgreSQL and Prisma**, self-hosted on Linux with Docker.

Right now I'm building **[Ordenla](https://ordenla.com)**, an offline-capable, tablet-first point of sale for Mexican food-service businesses, and running **[Kasump](https://kasump.com)**, where I deliver web projects for small businesses.

- 🔭 Currently building: Ordenla (multi-tenant SaaS POS) and an AI-powered pull request review bot
- 🧩 I like: offline-first architecture, self-hosting, and integrating LLMs into products that actually ship
- 💬 Ask me about: Next.js App Router, multi-tenant auth, VPS deployments, LLM API integration
- 📫 Reach me at: **o@kasump.com**
